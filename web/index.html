НОВЫЙ VPS

Добавить сервер

Оркестратор создаст отдельный SSH-ключ и проверит вход по нему. Пароль root не сохраняется. После установки вход по паролю будет отключён; существующие SSH-ключи сохранятся.

Сначала создайте имя в DuckDNS. Привязку к IP сервера оркестратор выполнит автоматически.

Настройки

Задайте настройки один раз. Они сохранятся вместе с данными оркестратора.
